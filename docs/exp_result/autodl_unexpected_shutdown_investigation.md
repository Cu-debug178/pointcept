## 因果链

```text
旧版本复评快速失败
-> 历史包装脚本进入 300 秒等待
-> 工作区随后 git pull 到新版本
-> 已运行的旧 Bash 进程不受文件更新影响
-> 倒计时结束并关闭实例
-> 同时运行的诊断日志在 hostname 后被截断
```

## 仍需排除的外部原因

- AutoDL 控制台配置的自动停止或预算策略。
- `/root/.bashrc`、cron、systemd timer 中的用户自定义任务。
- 另一台独立服务器上仍在运行的同类历史包装进程。

新安全启动器会在启动前停止历史包装进程，并持续写入心跳和退出码。若再次发生实例停止且没有 `.exit` 文件，则应把原因升级为 AutoDL 平台或系统级任务，而不是 Pointcept 复评代码。
